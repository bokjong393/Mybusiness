# ROADMAP.md — 90-Day Execution Plan

**Last updated:** 2026-08-29 · **Founder capacity:** 40+ hrs/week · **Budget:** <$100
**Principle:** SELL → DELIVER MANUALLY → LEARN → STANDARDIZE → AUTOMATE → SCALE

**Nothing is built until validation passes.** The only "product" in the first 60 days is a
Google Doc delivered on time.

---

## Days 1–7 — Remove the blockers

| | |
|---|---|
| **Objective** | Become capable of getting paid, and become credible to a stranger. |
| **Actions** | 1. **Solve payment collection** (Experiment E0) — open Payoneer/Grey/Geegpay, receive a real test payment. 2. Rewrite LinkedIn headline and About around the wedge sentence; remove implied seniority. 3. Review the existing work sample; decide if it is showable. 4. Build target list of 100 named prospects (consultancies, expansion leads, NGO programme managers) in a free spreadsheet. 5. Set up: free scheduler, a simple email address, an outreach tracker. |
| **Deliverable** | Working payment rail · rewritten profile · 100-prospect list · tracker |
| **KPI** | Test payment received (yes/no); prospects listed |
| **Success threshold** | Payment rail confirmed working + 100 named prospects |
| **Failure condition** | No rail works → **stop everything else**, escalate to alternatives (marketplace-held payments, a trusted intermediary abroad) |
| **Next decision** | Which single ICP to open with in week 2 |

## Days 8–14 — Build proof, open the channel

| | |
|---|---|
| **Objective** | Publish a sample that makes the credential gap irrelevant, and start conversations. |
| **Actions** | 1. Produce and publish the bilingual mini market brief (E1). 2. Pin it to LinkedIn Featured. 3. Begin outreach: 20 personalised messages/day, logged. 4. Create the marketplace profile and send the first 10 proposals (E5). 5. Publish 3 LinkedIn posts drawn from the research itself. |
| **Deliverable** | Published bilingual sample · 60 outreach messages sent · 10 proposals |
| **KPI** | Reply rate; proposal-to-interview rate |
| **Success threshold** | ≥8 replies from 60 (E2 pass) |
| **Failure condition** | <4 replies → wrong ICP, not wrong message. Change segment before sending more. |
| **Next decision** | Iterate message, or switch ICP |

## Days 15–30 — First revenue

| | |
|---|---|
| **Objective** | One paying customer. Price is secondary; the seal must break. |
| **Actions** | 1. 10 discovery conversations (E3). 2. Quote 5 qualified prospects at full price (E4). 3. Continue 20 messages/day and 5 proposals/week. 4. Deliver the first job **exceptionally** — over-deliver deliberately on job #1. 5. Ask for a written testimonial the day you deliver. |
| **Deliverable** | **First paid invoice** · first testimonial · 2 LinkedIn posts/week sustained |
| **KPI** | Revenue; testimonials |
| **Success threshold** | ≥1 paid job ($150+) **and** ≥3 prospects naming specific upcoming work |
| **Failure condition** | 10 conversations, 0 named projects → problem is not urgent; re-open Phase 3 |
| **Next decision** | Hold price, raise price, or change offer |

## Days 31–60 — Repeatability

| | |
|---|---|
| **Objective** | Prove job #1 was not luck. Move up the ladder from localization to research briefs. |
| **Actions** | 1. Win 2–3 more projects. 2. Sell the **first research brief** (M2) to a localization client or a warm lead. 3. Standardize delivery: brief template, intake questionnaire, quality checklist. 4. Raise prices on new clients once 3 jobs are delivered. 5. Publish the second bilingual sample — this time on a topic your buyers named in conversations. |
| **Deliverable** | 3+ delivered jobs · 1 research brief sold · delivery templates |
| **KPI** | Monthly revenue; AOV; close rate |
| **Success threshold** | **$500–$1,000 in month 2** and rising AOV |
| **Failure condition** | Revenue flat and every client is one-and-done → the offer has no repeat structure; redesign toward continuous-need buyers |
| **Next decision** | Which buyer type shows *continuous* need (the retainer candidates) |

## Days 61–90 — Recurring revenue and the first build

| | |
|---|---|
| **Objective** | Convert one client to a retainer. Build the minimum web presence — only now. |
| **Actions** | 1. Offer retainers to the first 3 satisfied clients (E6). 2. **Only if validation has passed:** build a single landing page — offer, proof, samples, pricing, booking link, email capture. Free hosting. 3. Start the free bilingual newsletter as research exhaust — audience asset, not revenue. 4. Systematize outreach into a repeatable weekly cadence. 5. Full 90-day review against every threshold in EXPERIMENTS.md. |
| **Deliverable** | ≥1 signed retainer · landing page live · newsletter #1 |
| **KPI** | MRR; churn; pipeline value |
| **Success threshold** | **≥$1,000 total revenue in month 3, with ≥$500 recurring** |
| **Failure condition** | 0 of 3 retainer offers accepted → buyers are episodic; target consultancies specifically |
| **Next decision** | Scale outbound, raise prices, or begin the data-product track (M7) |

## What gets built, and why — every feature justified

Nothing on this list is built before the validation gate it depends on.

| Business need | Feature | Expected impact | Gate |
|---|---|---|---|
| A stranger must understand the offer in 30 seconds | One-page landing site | Raises reply-to-call conversion | After first paid customer |
| Prove competence without a track record | 2 published bilingual samples | Removes the credential objection | Week 2 — **do this first** |
| Stop losing track of outreach | Spreadsheet tracker (not a CRM) | Makes the funnel measurable | Week 1 |
| Collect money | Payment rail + invoice template | **Without this there is no business** | Week 1 |
| Reduce back-and-forth on scope | Intake questionnaire | Faster quotes, fewer scope disputes | Month 2 |
| Deliver consistently as volume grows | Brief template + QA checklist | Protects margin and reputation | Month 2 |
| Capture interest that isn't ready to buy | Email capture + newsletter | Compounds the audience that doesn't exist yet | Month 3 |
| Sell the same research twice | Report/data product | Revenue decoupled from hours | Year 1, not before |

**Explicitly NOT building in 90 days:** customer dashboard, admin dashboard, authentication,
database, automated onboarding, CRM software, AI workflow tooling, mobile anything.
Every one of these is a way to feel productive while avoiding sales calls.
