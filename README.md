# Business Operating System

A side-hustle discovered, scoped, and planned from first principles — built around one founder's actual constraints rather than around a trendy idea.

**Current thesis:** AI has made *finding* companies free. It has not made *knowing which ones are worth contacting this month* free. We sell that judgment to small B2B agencies whose revenue depends on it.

**Status:** pre-revenue. Every claim in these files is a hypothesis until a stranger pays.

## Operating principles

1. Fall in love with profitable customer problems, not ideas.
2. Payment is the only real validation. Compliments, likes, and waitlists are not evidence.
3. Distribution beats product complexity.
4. Deliver manually until the process is understood. Only then automate.
5. Cash flow before scale.
6. AI is leverage, not the thesis.
7. Never sell capacity that a bad week would destroy.

**The loop:** find problem → sell solution → deliver manually → get paid → learn → standardize → automate → productize → scale.
