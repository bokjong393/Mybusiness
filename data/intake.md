## 4. Extracurriculars **(needed to start)**

This is the part that decides whether the plan survives past week three.

For each activity give a **floor** (the weekly hours below which the activity
effectively dies) and a **target** (the healthy amount you actually want), plus
a tier:

- **protected** — keeps its hours even in exam weeks. Reserve this for one or
  two things that genuinely matter to you.
- **flexible** — halved automatically during crunch weeks.
- **surplus** — suspended entirely during crunch weeks, runs on spare capacity.

| Activity | Tier | Floor hrs/wk | Target hrs/wk | Fixed timing, if any |
|---|---|---|---|---|
| Korean study | | | | |
| Business building | | | | |
| | | | | |
| | | | | |

Add anything else that takes real weekly hours — content creation, a side
income stream, gym, volunteering, a leadership role, a fellowship.

**On floors:** a floor of 0 means "drop this whenever convenient." Be careful
with that. Setting Korean to 0 for four months is how a language habit dies.
A floor of 2-3 hours keeps something alive through a bad month.
