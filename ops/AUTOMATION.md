# Automation Policy — Phase 15

**Rule: nothing gets automated until it has been done manually at least five times.** You cannot automate a process you do not understand, and the first five deliveries are where the real process gets discovered. Premature automation encodes your ignorance and makes it permanent.

**Second rule: automate the work, never the relationship.** The moment a client can tell they are talking to a script, the only thing that distinguishes us from a $9 Fiverr gig is gone.

---

## Process classification

| Process | Class | Notes |
|---|---|---|
| Choosing which agencies to target | **Human** | Judgment about fit. Cheap to do, expensive to get wrong. |
| Building the signal pool | **AI-assisted** | AI drafts candidates; human verifies every signal and date. |
| **Verifying a signal is still true** | **HUMAN — never automate** | This is the product. Automating it destroys the only thing we sell. |
| Writing the personalized outreach line | **AI-assisted** | AI drafts, human edits. A fully generated line reads generated. |
| Sending outreach | **Automatable** (with care) | Sequencing tools are fine. Never auto-send an unreviewed first line. |
| Follow-up scheduling | **Automatable** | Pure calendar logic. |
| Replying to a prospect | **HUMAN — never automate** | Speed and specificity of reply is a competitive advantage. |
| Sales conversations | **HUMAN** | Where trust is built and objections are learned. |
| Contact/email enrichment | **Automatable** | Tool work with no judgment involved. |
| Email verification | **Automatable** | Deterministic. |
| Formatting the deliverable | **Automatable** | Template + script. |
| Writing the "Why Now" line | **AI-assisted** | AI drafts from the verified signal; human keeps it honest. |
| Final quality read of a sheet | **HUMAN — never automate** | Read as the buyer. Delete anything you wouldn't send yourself. |
| Invoicing and payment chasing | **Automatable** | |
| Client onboarding questions | **AI-assisted** | Standard form, human follow-up. |
| Monthly client check-in | **HUMAN** | This is retention. It is not overhead. |
| Deciding what to build next | **HUMAN** | |

## Automation sequence, by trigger

| Trigger | Automate | Expected saving |
|---|---|---|
| After 5 manual deliveries | Sheet template + formatting macros | 30 min/pack |
| After 100 outreach messages | Follow-up sequencing | 2 hrs/week |
| At client #2 | Standard ICP intake form | 20 min/client |
| At client #3 | Saved signal-source checklist per signal type | 1 hr/pack |
| At client #4 | Email verification + enrichment pipeline | 45 min/pack |
| At client #5 | Written SOP good enough to hand to an assistant | Unlocks delegation |
| At $3,000 MRR | Consider software (Phase 11) — **only then** | — |

**The SOP at client #5 is the single highest-leverage artifact in this business.** It is what converts the founder's time into someone else's time, and it is the precondition for every revenue level above $5,000/month.

---

## When software becomes justified (the Phase 10/11 gate)

Build nothing until **all four** are true:

1. ≥ 3 paying clients on recurring retainers
2. ≥ $2,000 MRR
3. The same manual step has been repeated ≥ 20 times without changing shape
4. Automating it saves ≥ 10 hours/month, measured against actual logged hours

Until then the stack is: **Google Sheets · Gmail · LinkedIn · Calendly · a payment link · an AI assistant.** That stack can carry this business to roughly $3,000/month. Anything more elaborate before then is procrastination with a keyboard.

**First thing worth building, when the gate opens:** a signal-monitoring pipeline that watches defined sources for defined triggers and pre-populates candidate rows for human verification. That is the bridge from a service into Plan B — and eventually into a product.
